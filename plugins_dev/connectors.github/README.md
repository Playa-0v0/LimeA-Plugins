# GitHub

在 LimeA 中安装并启用插件，打开插件页并点击「连接 GitHub」。把页面显示的一次性验证码填到系统浏览器打开的 GitHub 授权页，确认应用是 LimeA Connector 后完成授权。插件会自动显示当前账号。

「管理授权仓库」用于安装应用并选择仓库。「管理 GitHub 授权」用于在 GitHub 检查和撤销账号授权。本机断开会删除 LimeA 保存的凭据，GitHub 端授权由用户在该页面撤销。

插件提供已授权仓库列表和有边界的 GitHub REST 查询、写入工具，覆盖仓库内容、分支和提交、议题与评论、拉取请求与审查、发布、部署以及自动化运行。模型先读取随插件提供的 github skill 和接口参考。写入遵循 LimeA 会话权限，审批内容与实际方法、路径和请求正文绑定。网络中断导致结果未知时，先在 GitHub 核对结果，再从插件页解除待核对状态。

设备授权和令牌刷新由 LimeA 宿主管理，凭据使用系统加密能力存入本机数据库，插件及模型不接触令牌。仓库内容和工具结果会进入当前对话，并可能交给用户选定的模型服务。

当前使用 GitHub.com，有界分页默认每页 10 条，上限 30 条。目录在插件内分页并返回条目名称、路径、类型、版本和大小等元数据，达到 GitHub 单目录 1000 项上限时标明可能不完整。正文与文件内容完整保留，工具结果超过 24,000 字节时明确失败；超大单文件暂不支持读取。GitHub 自动通知、GraphQL 讨论和项目看板、二进制附件及运行日志下载尚未接入。权限预留不会自动提供相应工具。首版不修改本机 Git 凭据。

开发时运行 `npm ci`、`npm test`、`npm run build`，然后从 `dist` 导入 LimeA。需要包含 GitHub 设备授权适配的新版宿主。
