# 壁纸与玻璃外观

为 LimeA 添加本地图片、静音视频、Wallpaper Engine 场景和网页壁纸，可调整面板不透明度、模糊、压暗、填充方式、帧率和暂停。需要支持插件接口版本 9 的主程序。

## 使用

在「设置 → 插件」导入 `dist` 并启用，点击插件卡片的「设置」。选择图片、视频或壁纸目录里的 `project.json`；也可扫描 Steam 已下载的工坊库。选择后自动保存，重启恢复。清除仅取消选择，不删除原文件。停用会恢复原生外观并关闭本地媒体服务。

0.1.1 新增「外框加深」：在工作区不透明度之外，只加深标题栏、左侧栏和四周留白，让外框更深、工作区更通透。默认 35%，可调为 0%–80%；0% 不额外加深。此项需要同时更新 LimeA 主程序。已有 0.1.0 可通过「从目录升级」选择本插件 `dist`，原有壁纸与设置会保留。

文件保留在原位置，移动或删除后需要重新选择。配置和壁纸列表存入宿主管理的 SQLite 数据库，不随插件版本更新重置。所有媒体默认静音，窗口隐藏时暂停；网页作者自建定时器是否暂停取决于引擎兼容性。玻璃外观开关只控制模糊，关闭后仍显示壁纸并保留不透明度设置；点击「恢复默认背景」或停用插件才恢复原生外观。

0.1.2 将设置中的操作按钮、下拉框、滑动条和开关接入本体控件。更新 LimeA 后，这些控件会自动跟随本体主题和键盘操作；滑动条拖动时显示数值，松手后保存。旧宿主仍可使用原生控件。通过「从目录升级」选择新版 `dist`，已有设置保持不变。

## 复用和边界

0.1.3 将壁纸列表改成预览网格。工坊项目优先读取 `project.json` 的 `preview`，再查找常见 `preview.*`；本地图片使用自身缩略图。已有项目无需重新扫描，选择和原有配置继续保留。宽窗口三列、窄窗口两列，卡片显示名称、类型和已选标记。没有封面或损坏时显示占位，仍可选择。

缩略图需要更新后的 LimeA 主程序提供 `images.thumbnail`：复用宿主 Sharp，输入限制 32 MiB / 64 MP，输出最多 320×180 的静态 WebP。动图封面选择后续帧，避免开场黑帧；不在网格内同时播放动图或视频。仅加载可视区域附近的封面，最多两项请求；前端最多缓存 96 项，后台按文件大小、修改时间和变更时间缓存 128 项，停用后释放。未提供封面的独立视频不额外抽帧；旧主程序会提示更新以显示预览。

- 直接保留 dsh-wallpaper-engine 提交 `17f659a` 的 Steam 发现和项目扫描代码，见 `vendor/`；渲染装配参考其 `lib/webwallgl/renderer.js`。
- WebWallGL 3.0.1 负责场景解析、WebGL 渲染和网页兼容层，不自行实现场景引擎。引擎完整打包，运行不下载脚本。
- serve-handler 6.1.7 负责媒体流、范围请求和类型处理，插件只添加随机资源凭据与目录限制。
- 插件后台是用户信任的本地代码。壁纸脚本运行在独立本机来源的受限框架中，不获得 LimeA 桌面桥接。媒体端口只监听回环地址，路径有随机凭据且只读；单文件选择不开放其同目录的其他文件。
- 不启动应用程序类壁纸，不下载工坊内容。复杂场景、系统音频响应、依赖 Wallpaper Engine 安装内置素材的场景及特殊视频编码可能不兼容；失败在设置页显示，不伪装播放成功。此版未包含转码、桌宠和特效。

## 开发

```sh
npm ci
npm test
npm run build
```

桌面验证：设置 `LIMEA_REPO_DIR` 和 `LIMEA_TEST_APP_DIR` 指向已构建的宿主后运行 `npm run test:desktop`。使用临时用户目录，不修改日常配置。
