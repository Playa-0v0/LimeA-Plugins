# Gmail（待谷歌认证）

在 LimeA 的插件管理中安装并启用 Gmail，打开插件，点「连接 Gmail」。在系统浏览器完成 Google 授权后，返回插件页查看账号和插件许可；如果显示「尚未允许使用当前连接」，点击「允许插件使用」。在下一条消息中可以要求 LimeA 查找邮件、阅读会话、创建草稿、发送邮件及整理收件箱。收件地址、主题及正文会随发送操作进入宿主审批流程。

例如「找出上周关于项目排期的邮件，给我一份摘要」或「给 alex@example.com 拟一封跟进草稿，先留在草稿箱」。

本版支持纯文本邮件和一个已连接邮箱。附件只显示名称、类型和大小。需要支持 Google 连接的 LimeA 宿主。

开发时在本目录运行 `npm ci`、`npm run build` 和 `npm test`，可从生成的 `dist` 目录导入插件。
